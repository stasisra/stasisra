# Изменения Workspace 0.2

Согласованный UX перенесён в рабочее приложение с серверным сохранением: темы, общие контакты и роли, несколько исполнителей, подзадачи, мероприятия, быстрые комментарии и вопросы, дедлайны, единые фильтры, Гант, вложения и просмотр Office, печать / PDF / CSV / XLSX с описаниями.

Добавлены SQL-миграция и повторяемый перенос старых тегов. Старые задачи, комментарии и вложения сохраняются. У неоднозначной ветки тему нужно выбрать вручную. Созданные из тегов родители являются настоящими задачами; перенос не заменяет уже существующую иерархию. Исходные теги и назначения остаются в БД для проверки.

Сервер проверяет даты, время, ссылки на справочники, циклы, наследование темы и ревизии. Создание задач, заметок и загрузки имеют идентификаторы для повторной попытки. Сетевой сбой не выдаётся за успешное сохранение; черновик не очищается после отклонённого запроса. Нормализованные изменения выполняются транзакционно. Старые способы записи через API закрыты, чтобы они не обходили эти проверки.

Исправлено воспроизведённое падение нативного `better-sqlite3` 11.10.0 внутри Prisma на Node 24: адаптер и приложение используют одну закреплённую версию 12.11.1. Отдельная сессионная cookie новой версии не вытесняет сессию старой программы на другом порту.

Установка Windows создаёт отдельную копию на 3002 из `task-gantt-app-fixed` на 3001; актуальная SQLite с WAL копируется через backup API, без подмены источника. Повторная установка не копирует старую базу поверх новой.

## Практические ограничения

- Проверки выполнены на Linux, Node 24.19.0 и Chromium; непосредственный запуск `.cmd` на Windows здесь не выполнялся. JavaScript-помощник установки проверен с настоящей SQLite в WAL и повторным запуском.
- Пользовательская база находится на его Windows-компьютере; облачные тесты используют синтетические данные. После переноса проверьте «Без темы», ответственных и созданные группы.
- Встроенный просмотр DOCX и Excel предназначен для чтения; точное воспроизведение сложной вёрстки Office не гарантируется. Старый DOC требует преобразования в DOCX либо внешней программы, формулы и макросы не выполняются.
- Браузерная печать зависит от настроек принтера: A4, масштаб 100%, колонтитулы браузера отключены. Очень длинные записи могут продолжаться на следующем листе.
- Старые вложения только из IndexedDB автоматически не импортируются. SQLite-вложения сохраняются при копировании базы.
- Статус и процент выполнения остаются независимыми. Скрытие справочника не снимает существующие назначения; удаление с заменой меняет связи явно.
- В этом локальном выпуске не выполнялась миграция на Next 16 / Prisma 7 и не устранены все ранее известные замечания npm audit к транзитивным зависимостям. Полный новый аудит зависимостей не заявляется. Публичное размещение в Интернете требует отдельной оценки и HTTPS.

Архив не содержит `.env`, пользовательских баз, `node_modules`, `.next`, старых архивов и демонстрационных задач. Инструкции — в README.md.
