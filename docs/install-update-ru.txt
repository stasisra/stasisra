Task & Gantt 0.4.2 — обновление Windows

1. Проверьте, что в рабочей папке C:\Distr_Local\task-gantt-app-next есть
   start-next.cmd, .env, prisma\dev.db и ссылка node_modules. Оставьте
   соседнюю папку C:\Distr_Local\task-gantt-app-workspace с её библиотеками.
2. Остановите Task & Gantt на порту 3003 сочетанием Ctrl+C в окне запуска.
   Если Windows запросит подтверждение остановки, подтвердите.
3. Распакуйте task-gantt-update-0.4.2.zip отдельно от рабочей папки,
   например в C:\Distr_Local. Получится папка task-gantt-update-0.4.2.
4. Из распакованной папки запустите update-next.cmd. Дождитесь сообщения
   Update complete. Если приложение находится в другом месте, запустите
   из командной строки

   update-next.cmd "D:\путь\к\task-gantt-app-next"

5. В рабочей папке запустите start-next.cmd. Откройте привычный адрес
   http://127.0.0.1:3003 или http://localhost:3003, чтобы сохранить настройки
   браузера. Выполните Ctrl+F5 и войдите с прежним паролем. Откройте
   существующую задачу с комментарием и файлом и проверьте список мероприятий.

Резервная копия и откат

Перед изменениями помощник проверяет контрольные суммы пакета и сохраняет
копии в task-gantt-app-next\_updates\<дата-время>. В папке будут
database-before.db, settings-before.env, копии заменяемых файлов и
previous-build с прежней сборкой. В копию SQLite попадают и изменения из WAL.
Храните папку _updates вместе с рабочей установкой. Копия содержит ваши данные.

Сообщение Update rolled back означает, что прежние база, файлы программы
и сборка восстановлены. Запустите прежний start-next.cmd из рабочей папки.
Если появилось Rollback incomplete, оставьте программу остановленной.
Сохраните полный текст ошибки и путь Backup из этого же окна.

Для обновления используются установленные библиотеки и Node 22.12+ либо 24.
При наличии C:\Distr_Local\node-v22.23.4-win-x64 сценарий выберет этот Node.
После скачивания пакета переустановка библиотек и повторный импорт Excel
не требуются. Для обновления рабочей базы используйте только update-next.cmd.

Что изменилось в карточках

«Сохранить» оставляет карточку открытой. «Сохранить и выйти» закрывает её
после успешного сохранения. «Добавить итог в задачи» сохраняет текст в
мероприятии и добавляет его копию с переходом к источнику в рабочую задачу.
После правки итога повторно выберите нужные задачи, чтобы обновить их копии.
«Google Calendar» открывает черновик события, где вы подтверждаете сохранение.
Событие без времени открывается как целодневное, при одном указанном времени
на одну дату используется длительность в один час.

Проверки выполнены на отдельной базе под Linux с полной предыдущей сборкой.
Запуск Windows-команд на Windows в этой среде недоступен.
