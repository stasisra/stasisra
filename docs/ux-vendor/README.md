# Локальные средства просмотра Office

Библиотеки используются только автономным UX-макетом; зависимости рабочего приложения не менялись. Исходные пакеты скачаны из npm registry, их tarball SHA-512 проверены по `dist.integrity`. Версии, источники и SHA-256 файлов сохранены в `manifest.json`. Лицензии размещены рядом.

- mammoth 1.13.0 — преобразование DOCX в HTML для чтения.
- DOMPurify 3.4.17 — очистка результата преобразования; ссылки и внешние изображения не загружаются.
- SheetJS CE 0.20.3 из пакета @e965/xlsx — чтение Excel. Макросы не выполняются, формулы не пересчитываются; содержимое ячеек экранируется.
- examples.js — сгенерированные демонстрационные DOCX и XLSX без пользовательских данных.

Файлы подключаются локально; CDN и внешние сервисы просмотра не используются.
