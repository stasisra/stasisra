# Проверки версии 0.4 — 3 ноября 2026

Среда: Linux, Node 24.19.0, Chromium; синтетические данные. Текущая база пользователя находится на Windows и в облаке не менялась.

- 40 модульных/интеграционных тестов проходят без пропусков.
- 16 браузерных сценариев проходят на production-сборке: прежние 13 и новые сценарии карточек, выбора/печати, контактов и редакторов.
- TypeScript, ESLint, синтаксис JavaScript и production build проверены.
- Настоящий пакет распакован отдельно и применён к схеме из опубликованного установочного ZIP 0.3. Добавлены синтетические рабочее дерево, тестовая тема, мероприятие, связи, комментарий и BLOB-файл. После обновления строки всех рабочих таблиц, байты файла и настройки сопоставлены с исходными; различий нет. Обновлённая программа запущена на 3003: прежний вход, файл, широкая карточка и сохранение @ проверены в Chromium.
- Обновление при искусственном сбое сборки уже после миграции откатывает схему/данные, код, предыдущую сборку и настройки. Повреждённый payload отклоняется до записи. Используется согласованный SQLite backup.

Новые проверки: профиль контакта с несколькими темами, сохранение полей при старом API, объединение профилей/связей и перенаправление упоминаний; контекст @ по нескольким темам, кириллица и пробелы, мышь/Enter, отсутствие автоматического назначения роли; сохранение переносов строк после настоящего Enter; развернутый редактор; переход из несохранённого описания темы к редактированию контакта и возвращение с сохранённым черновиком и правильным контекстом; отдельное удаление пункта/связи без удаления рабочей задачи; навигация с сохранением правок; перемещение; печать выбранной группы с описанием; необязательные контактные блоки, их состояние на момент добавления, обновление без дублей и исключение из печати; читаемые ссылки без служебного формата в выводе.

Windows .cmd непосредственно не исполнялся. CLI использует Node 22.12+/24 и установленный tsx по имени пакета, без абсолютного Windows ESM-specifier. Реальные данные после обновления проверяются на компьютере пользователя. Просмотр Office и очень большие деревья имеют ограничения из README/FIXES. Архивы проверяются на CRC; опубликованный ZIP скачивается обратно и сверяется по SHA-256.

# Проверки версии 0.3 — 1 ноября 2026

Среда: Linux, Node 24.19.0, Chromium. Использовались синтетические данные и отдельные временные SQLite. Фактическая база на Windows находится у пользователя и в облаке не подключалась.

- `npm run lint`, `npm run typecheck`, `npm run check:workspace` — успешно.
- `npm test` — **36 тестов, 36 успешно**, без пропусков.
- `npm run build` — production-сборка Next.js 15.5.28 успешна.
- `npm run test:e2e` — **13 браузерных сценариев, 13 успешно** на production-сервере 3100.
- Архив распакован в отдельную временную папку; setup-next создал пустую базу, сохранил вход ADMIN и выполнил production-сборку с библиотеками прежней установки. Распакованная программа запущена на 3003: успешны вход прежним паролем, проверка отсутствия старых задач/тем, сохранение задачи только с названием и отображение в Chromium без ошибок JavaScript.

Модель и SQLite: реальные миграции, наследование темы и смена ветки, циклы, даты, независимые роли, вложенные мероприятия, объединённые темы/люди, перенос повестки между мероприятиями с потомками, сохранение порядка, отклонение устаревшего редактирования. Превращение собственного пункта в рабочую задачу сохраняет обсуждения и один оригинал вложения в двух контекстах. Проверены повторы создания/загрузки, удаление родителя с сохранением детей и транзакционный откат.

Экспорт/импорт: актуальные записи открытой SQLite в WAL, полные описания свыше 40 тысяч символов, XLSX с сохранёнными ID, JSON без паролей и .env, оригиналы файлов с SHA-256. Проверены отбор, удалённый родитель с оставленным ребёнком, исторический автор, ошибка при цикле, пропавших строках, другом отборе, недостающем/изменённом файле; успешный перенос и повтор без дублей. Через браузер выполнены выбор Excel и папки, предпросмотр без создания задач и импорт с проверкой точных байтов вложения.

Браузерные сценарии также проверяют вход/выход, безопасный next, закрытую регистрацию и CSRF; карточки и черновики; две вкладки; одинаковый состав фильтров и печати/CSV/XLSX/PDF; реальные локальные DOCX и XLSX без внешних запросов; справочники с заменой; валидацию мероприятия и Гант; повтор загрузки файла после сбоя; дерево выбора веток и исключений с восстановлением после обновления; мероприятие SP+ВНЖ с собственными людьми, вопросами, подготовкой, календарём и печатью описаний/изображений; изменение порядка повестки; свободные теги и перевод пункта в тему.

Дерево фильтров отдельно проверено на 5000 уровнях без рекурсивного переполнения. Это проверка алгоритма выбора, не заявление о производительности всего интерфейса на таком объёме.

Windows `.cmd` непосредственно не запускался; перенос реального отобранного списка ожидает Excel пользователя. Office предназначен для просмотра, с ограничениями из README. Архивы проверяются на CRC; опубликованный файл скачивается обратно и сравнивается по SHA-256. Полного нового аудита всех транзитивных npm-зависимостей этот выпуск не заявляет.
