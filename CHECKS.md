# Проверки Workspace 0.2

Среда: Linux, Node 24.19.0, Chromium. Только синтетические данные и отдельные временные SQLite-базы. Пользовательская база с Windows не подключалась.

- `npm run prisma:generate` — клиент с новой схемой сгенерирован.
- `npm run typecheck` — успешно.
- `npm run lint` — успешно.
- `npm run check:workspace` — синтаксис рабочего JavaScript корректен.
- `npm test` — **22 теста, 22 успешно**, без пропусков.
- `npm run build` — production-сборка Next.js 15.5.28 успешна.
- `npm run test:e2e` — **8 браузерных сценариев, 8 успешно**, production-сервер и временная БД.

Модульные и интеграционные проверки: реальные SQL-миграции и согласование старой NamePolicy; классификация тегов без потери задач / комментариев / файлов; отсутствие демонстрационных задач; объединение Наташи; удаление Козуба из составных назначений; неоднозначные темы; повторный перенос; наследование темы и смена всей ветки; циклы и календарные даты; транзакционный откат; роли, замена и удаление справочников; ревизии; повтор запросов без дублирования; удаление родителя с сохранением потомков.

Помощник установки: согласованная копия актуальной записи из открытой SQLite в WAL; сохранение прежнего хеша пароля; независимость новой базы; повторный запуск без перезаписи; отказ при частично подготовленной папке.

Браузерные сценарии:

1. Вход, безопасный next, запрет регистрации, отклонение стороннего Origin, безопасный снимок, выход.
2. Создание через интерфейс с несколькими исполнителями, описанием, вопросом и вложением; повтор после ошибки; повторное открытие, просмотр / скачивание файла, быстрый комментарий.
3. Две вкладки: устаревшее сохранение отклоняется, черновик остаётся, свежая карточка загружается явно.
4. Совпадение строгой выборки по теме / людям / включительным датам с обычным списком, встречей, CSV, настоящим XLSX и PDF браузера; полные описания; несколько тем и дедлайны.
5. Настоящие DOCX и XLSX из серверных вложений, кириллица, переключение листов, отсутствие внешних запросов при просмотре.
6. Добавление контакта, роль ответственного, скрытие / восстановление, удаление с заменой без потери задачи.
7. Валидация времени мероприятия, сохранение часового пояса и места; переходы со старых адресов и рабочий Гант.

8. Сбой загрузки файла после создания задачи: карточка и файл остаются для повторной попытки, повторное сохранение не дублирует задачу и сохраняет оригинал.

Дополнительно вручную проверен встроенный PDF-просмотр в production-CSP: настоящий прикреплённый PDF отображается в Chromium; извлечённый текст напечатанного PDF содержит полное многострочное описание и вопрос. Контрольные суммы трёх Office-библиотек сверены с манифестом.

После воспроизведённого нативного падения сервера со старым драйвером зависимость исправлена и браузерный набор выполнен заново полностью. Windows и внешний GitHub Actions workflow здесь не запускались. Ограничения перечислены в FIXES.md.
